# Career Quest (HackAlem AI, трек Halyk Bank) — инструкции для агента в этом репозитории

5 часов на разработку. Оценка — 100 баллов: соответствие задаче 25, техническая реализация 25,
README и воспроизводимость 25, ценность/применимость 15, потенциал/оригинальность 10.

## Обязательно
- **Коммитить и пушить минимум раз в час** без явного запроса — прямое требование правил
  хакатона, отсутствие прогресса за час = дисквалификация.
- Никакой имитации: рекомендация должна реально считаться из данных (грейд, разрыв по
  навыкам, критичность навыка для перехода, история участия), а не быть захардкоженной.
  Явный запрет из ТЗ: рекомендация по одному полю профиля под видом AI.
- Обоснование рекомендации — минимум 3 фактора: грейд, разрыв по навыкам, история участия,
  требования следующего уровня.
- Решение обязано уметь загружать ДОПОЛНИТЕЛЬНЫЕ профили/историю в формате датасета —
  жюри на защите загружает три проверочных профиля.
- Основная функциональность НЕ должна жёстко зависеть от внешнего API-ключа (LLM — это
  улучшение объяснения, а не единственный источник рекомендации) — иначе жюри без ключа
  не сможет воспроизвести решение (критерий «README и воспроизводимость», 25 баллов).
- Запуск одной командой (см. ТЗ, «Инфраструктура»). `.env`/ключи — никогда не коммитить.
- Реальные персональные данные — запрещены; используем только синтетический датасет.

## Стиль
- Комментарии и коммиты — по-русски, если не сказано иное. Коммиты коротко, по смыслу.
